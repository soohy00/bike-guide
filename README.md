# 자전거 첫걸음 (bike-guide)

자전거를 처음 타는 사람을 위한 **정비·입문 가이드 웹 앱**이에요.
차 정비 앱처럼 주행 거리를 세고, 부품 교체 시점을 알려 줘요.

## 기능

| 탭 | 하는 일 |
| --- | --- |
| 🏠 홈 | 총 주행 거리, 지금 할 일 (급한 부품 3개), 고장 버튼, 타기 전 점검 |
| 🔩 부품 | 체인·오일·패드·타이어·카세트·바 테이프·케이블·샵 점검의 닳은 정도. "오늘 교체했어요" 버튼. 같은 모델 주인들이 많이 쓴 부품 (**예시 데이터**) |
| 🆘 고장 | 증상을 고르면: 왜 생겼는지, **필요한 것 (내 자전거 규격으로)**, 순서, 샵에 갈 때 |
| 📚 배우기 | 초보 수업 7개: 1분 점검, 바람 넣기, 체인 오일, 기어, 준비물, 안전, 부품 이름 |
| 🚴 주행 | 휴대폰 GPS 기록 + 손으로 입력. 최근 30일 통계, 경로 모양 |

## 지금 정한 것

- **웹 앱** (휴대폰 브라우저, 홈 화면에 추가 가능). 서버는 없어요.
- **로드 자전거**만 먼저 넣었어요.
- 데이터는 **브라우저 (localStorage)** 에만 저장해요.
- "같은 모델 주인들이 많이 쓴 부품"은 **예시 데이터**예요. 화면에도 "예시"라고 써 있어요.
- 교체 주기는 평균값이에요 (`src/data/parts.ts`).
- 디자인은 `DESIGN.md` (Linear 스타일, 다크 모드만)를 따라요. [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)에서 가져왔어요 (MIT).

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 배포용 빌드 (dist/)
```

## 폴더

```
src/
  data/        자전거 모델, 부품, 추천 부품(예시), 고장, 수업 내용
  lib/         교체 시점 계산, GPS 거리 계산, 저장, 라우터
  screens/     화면
  components/  공통 UI
```
